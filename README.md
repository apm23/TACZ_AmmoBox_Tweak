# TACZ AmmoBox Tweak

Minecraft 26.2 Fabric addon for TACZ Refabricated.

Target behavior:
- Iron Ammo Box: 1500 ammo
- Gold Ammo Box: 4000 ammo
- Diamond Ammo Box: 6000 ammo
- Diamond Ammo Box Lv.2: 10000 ammo, same visual model as Diamond

Recipes:
- Iron: chest center + iron ingots north/south/east/west
- Gold: chest center + gold ingots north/south/east/west
- Diamond: chest center + diamonds north/south/east/west
- Diamond Lv.2: Netherite Ingot + Diamond Ammo Box + Netherite Ingot

Tooltip target: `Ammo: current / capacity`.
